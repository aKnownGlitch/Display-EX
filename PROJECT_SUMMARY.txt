WHAT THIS PROJECT DOES:
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

This Arduino application monitors DCC (Digital Command Control) commands
from a Command Station-EX and displays real-time track status on an
ILI9486 touchscreen display.

Current monitoring:
  ✓ Track Power (ON/OFF) - Color coded red/green
  ✓ Turnout Status (3 turnouts) - Shows THROWN or CLOSED
  ✓ Locomotive Throttle (Loco 3) - Display 0-255 speed with bar graph
  
Display Updates: Every 1 second
Communication: Serial 115200 baud (USB or UART)

SERIAL PROTOCOL (How it works):
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

The Command Station sends plain text messages over serial:

   POWER:ON              Power is enabled on track
   POWER:OFF             Power is off
   
   TURNOUT:1:THROWN      Turnout 1 is diverging
   TURNOUT:1:CLOSED      Turnout 1 is normal
   TURNOUT:2:THROWN      Turnout 2 is diverging
   TURNOUT:2:CLOSED      Turnout 2 is normal
   TURNOUT:3:THROWN      Turnout 3 is diverging
   TURNOUT:3:CLOSED      Turnout 3 is normal
   
   THROTTLE:3:0          Locomotive 3 at 0 speed (stopped)
   THROTTLE:3:128        Locomotive 3 at half speed
   THROTTLE:3:255        Locomotive 3 at full speed

Message Format:
   • Terminated with LF (\n) or CR+LF (\r\n)
   • Case insensitive (can use lowercase or uppercase)
   • One message per line
   • No spaces in message
   
Example serial communication:
   
   From Command Station:
   > POWER:ON
   > TURNOUT:1:CLOSED
   > THROTTLE:3:0
   > THROTTLE:3:50
   > THROTTLE:3:100

HARDWARE REQUIREMENTS:
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

✓ Arduino Mega 2560 microcontroller
✓ ILI9486 3.5" TFT Display (480x320 pixels)
✓ USB cable (for programming and optional serial communication)
✓ Jumper wires
✓ 5V power supply (1A minimum)
✓ Optional: Serial adapter for Command Station connection (if not USB)

Wiring (see docs/HARDWARE_SETUP.md for detailed diagram):

   Arduino Pin → Display Pin
   50 (MISO)   → 12 (SDO)
   51 (MOSI)   → 11 (SDI)
   52 (SCK)    → 13 (SCK)
   10          → 10 (CS)
   9           → 9  (DC/RS)
   8           → 8  (WR)
   7           → 7  (RD)
   6           → 25 (RST)
   GND         → GND (pins 1,2,20)
   5V          → VCC (pins 3,4)
   5V          → LED+ (19)
   GND         → LED- (20)

TROUBLESHOOTING QUICK GUIDE:
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

Display not showing anything:
   1. Check power (5V to VCC pins)
   2. Run Display-Ex-Test.ino
   3. Try different rotation values (0, 1, 2, 3)
   4. See HARDWARE_SETUP.md troubleshooting section

Display shows garbage:
   1. Try rotation: tft.setRotation(1); (change value)
   2. Check SPI wiring (pins 50, 51, 52)
   3. Verify CS, DC, WR, RD connections
   
Serial messages not received:
   1. Check baud rate is 115200
   2. Verify TX/RX connections (may need to cross-over)
   3. Try loopback test: Send and check Serial Monitor
   4. See HARDWARE_SETUP.md serial section

Compilation errors:
   1. Verify libraries installed (Adafruit GFX, MCUFRIEND_kbv)
   2. Verify board selection: Arduino Mega 2560
   3. Clear Arduino cache: File → Preferences → More Options
